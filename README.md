# Tarea 3 - Java con NetBeans

Proyecto Maven de Apache NetBeans con los 6 ejercicios de la tarea. Todo el codigo esta en el paquete `com.tarea3`.

Abrir la carpeta en NetBeans (File > Open Project) y ejecutar. La clase principal `com.tarea3.MenuPrincipal` abre un menu con los 6 ejercicios; cada formulario tambien se puede ejecutar solo (Shift+F6).

Los archivos se leen y escriben en la carpeta `temp` de la raiz del proyecto.

| # | Ejercicio | Paquete / formulario | Archivo en `temp` |
|---|-----------|----------------------|-------------------|
| 1 | Control de Ventas Semanales | `com.tarea3.ventas.FrmVentas` | `ricardogonzalez_reporte_ventas.txt` (se genera) |
| 2 | Registro de Asistencia | `com.tarea3.asistencia.FrmAsistencia` | `ricardogonzalez_asistencia.txt` (se genera) |
| 3 | Lector y Analizador de Temperaturas | `com.tarea3.temperaturas.FrmTemperaturas` | `temperaturas.txt` (6 registros) |
| 4 | Biblioteca de Discos Musicales | `com.tarea3.discos.FrmDiscos` | `discos.csv` (5 registros) |
| 5 | Plataforma de Streaming (clases `Artista`, `Cancion`) | `com.tarea3.streaming.FrmStreaming` | - |
| 6 | Catalogo de Videojuegos (clase `Videojuego` + `ArrayList`) | `com.tarea3.videojuegos.FrmVideojuegos` | - |
